# fare_prediction_custom_training
## Overview
This project builds a scalable machine learning pipeline to predict taxi fares using historical NYC taxi trip data. The system leverages PySpark for distributed data processing and model training and runs on a Google Cloud Platform (GCP) cluster to efficiently handle large-scale trip datasets.

## Objectives
- Predict taxi trip fares based on trip characteristics and relevant features.
- Build a scalable training pipeline using PySpark.
- Deploy the pipeline on a GCP cluster environment.
